## 可复现启动方式

先执行 `npm ci`（首次安装或依赖变化时）和 `npm run build`。每个服务使用独立 PowerShell 终端，以下进程环境覆盖不会改写 `.env.local`。

规则服务：

```powershell
$env:OPENAI_API_KEY = ' '
$env:DATABASE_URL = ' '
node node_modules/next/dist/bin/next start -p 3210
```

正常 mock 单独运行 `node scripts/mock-llm.mjs 3999`，异常 mock 单独运行 `node scripts/mock-llm.mjs 3998 --garbage`。应用分别启动：

```powershell
$env:OPENAI_API_KEY = 'mock'
$env:OPENAI_BASE_URL = 'http://127.0.0.1:3999/v1'
$env:DATABASE_URL = ' '
node node_modules/next/dist/bin/next start -p 3211
# 异常模式在另一终端使用 3998/v1 和 -p 3212。
```

在另一终端执行上表测试命令；结束后停止所有测试服务。本次 3 个应用进程及 2 个 mock 进程均已停止。新增脚本仅允许 localhost/127.0.0.1，且要求 health 为 fallback/memory；仍应只指向专用测试实例，因为会创建 JD、推荐和训练记录。
