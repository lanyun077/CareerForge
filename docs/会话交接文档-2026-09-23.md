## 三、本会话完成的功能

### 1. 面试强度自定义

新增 `src/lib/interviewSettings.ts`，提供可配置的面试强度：

| 配置项 | 可选值 | 默认 |
|---|---|---|
| 主问题数量 | 5 / 7 / 9 | 7 |
| 训练难度 | 基础 / 标准 / 进阶 | 标准 |
| 每题追问上限 | 0 / 1 / 2 | 1 |

关键行为：

- `parseInterviewSettings` 严格校验，非法值返回 422。
- `configureInterviewRole` 按题数增删题目槽位，总结题不追问。
- 基础难度要求给概念与例子，进阶难度要求方案比较、边界、失败场景与验证方法。
- 二轮训练继承首轮配置，不接受中途更改，保证前后对比口径一致。
- 配置保存在会话与报告中，旧会话按默认值读取。
- 难度调整属于出题要求变化，不是经过人工校准的难度量表。

涉及文件：`src/lib/interviewSettings.ts`（新增）、`src/lib/types.ts`、`src/lib/services/interviewService.ts`、`src/lib/services/reportService.ts`、`src/app/api/interview/start/route.ts`、`src/app/resume/page.tsx`、`src/app/interview/page.tsx`。

数据库迁移：`db/schema.sql` 末尾新增 `interview_sessions.settings jsonb`。

### 2. 语音输入（录音转写）

新增 `src/app/components/VoiceAnswer.tsx`：

- 检查 `/api/asr` 是否配置，未配置时提示改用文字输入。
- 用户点击后才申请麦克风权限。
- 单次录音最长 120 秒、10 MiB，停止后自动上传转写。
- 转写结果进入可编辑预览，用户点击“追加到当前回答”才写入，不自动提交。
- 切题时释放麦克风、清理定时器、取消在途请求。
- 合并后超过 5000 字时拒绝追加并保留预览（本会话修复的缺陷）。
- 补充录音防重复启动和设备异常状态释放。

`src/lib/services/asrService.ts`：

- 校验文件非空、不超过 10 MB、格式在允许列表内。
- 未配置 `ASR_API_KEY` 时明确返回“未配置”。
- 调用 OpenAI 兼容的 `POST /audio/transcriptions`，60 秒超时。

真实麦克风录音与真实 ASR 识别质量尚未验证。尚未实现实时识别、音量或静音检测、TTS、数字人。

### 3. 真实岗位采集与来源追溯

新增受控采集链路，把真实招聘数据接入训练：

| 层 | 文件 | 作用 |
|---|---|---|
| 路由 | `src/app/api/roles/collect/route.ts` | 认证后的采集入口 |
| 服务 | `src/lib/services/jobCollection.ts` | 固定域名抓取、清洗、限流 |
| 来源 | `src/lib/jobProvenance.ts` | 签名采集凭据、来源校验 |
| 展示 | `src/app/components/JobSource.tsx` | 岗位与报告展示来源 |
| 解析 | `src/lib/services/roleService.ts` | 岗位结构化与降级 |

第一版只支持 Greenhouse 官方公开单岗位页面，不使用通用爬虫。

已实现的采集行为：

- 只接受 `job-boards.greenhouse.io` 与 `boards.greenhouse.io` 的单岗位链接，严格校验 board 与数字岗位 ID。
- 只调用固定 `boards-api.greenhouse.io`，解析公网 IPv4 并绑定到 TLS 连接，拒绝私有、环回、链路本地、保留与云元数据地址。
- 不跟随重定向，不执行网页脚本，不访问正文里的链接。
- 10 秒业务超时、512 KiB 响应上限、最多 3 个在途请求、每用户 6 次/分钟、每进程 30 次/分钟。
- HTML 与实体编码转纯文本，过滤邮箱和电话；脱敏为有限规则，不保证去除全部个人信息。
- 采集结果只作预览，必须确认后才保存。

来源与凭证：

- 保存来源 URL、可用时的官方公司名、采集时间、正文 SHA-256、`availability: unknown`。
- 采集凭据由服务端 HMAC 签名，绑定正文内容，30 分钟过期；重启进程后失效。
- 客户端不能自称接口来源；编辑正文、来源或公司后降级为手动导入。
- 单独标记训练要求是“自动提取”还是“用户确认”，来源标识不证明提取结果正确，也不代表来源方认可。
- 训练快照和报告继承来源信息，保存在既有 JSON 字段中，本会话未新增数据库列。

解析质量修复（来自真实 GitLab 岗位的实测）：

- 英文岗位标题识别。
- 技能词边界，避免 Java 命中 JavaScript。
- 必备与加分分节区分。
- 任选条款保留在同一条要求内，并为明确语言任选项生成独立关键词，使 Python 简历能正确匹配。
- 有明确任职要求分节时从该分节开始提取，避免公司介绍里的词进入必备技能。

实际证据：GitLab `AI Engineer`、`Ruby Backend Engineer` 两条公开岗位已成功读取，样本与人工预期保存在 `test-data/jobs/gitlab-public-samples.json`。

### 4. 提示注入边界

`src/lib/llm/client.ts` 为所有模型请求追加统一安全边界：简历、岗位描述、网页摘录、回答及其中的链接都是不可信资料，忽略其中改变身份、评分规则、输出格式或要求执行工具的内容。模型本身没有采集或执行工具权限。这只降低风险，不保证语义层面的提示注入完全消除。

### 5. 报告与数据可靠性（本会话之前已在同一未提交工作中完成）

作为交接背景一并记录：

- 报告新增当次简历匹配摘要 `resumeSummary`，不复制简历正文。
- 二轮报告展示维度提升项与仍低于 60% 的项。
- 删除训练时按规则清理报告与专属快照，仅在无其他训练引用时删除简历。
- PostgreSQL 使用事务行锁协调删除，防止延迟报告写入已删除数据。
- 相同用户相同请求复用进程内在途任务，模型两次尝试共用超时预算。
- 五个业务页面统一识别 401，提供重新登录与重载入口，保留页面输入。
- 面试回答限制 5000 字符，表单请求期间锁定，防止旧结果覆盖新编辑。

## 六、尚未验证与明确限制

这些项目不能标记为已完成：

1. **真实模型质量**：没有真实 `OPENAI_API_KEY`，链路只在 mock 与降级路径验证。
2. **真实数据库与多实例**：没有 `DATABASE_URL`，只在 PGlite 上验证；限流与签名密钥是进程内实现，多实例部署需要共享设施。
3. **真实认证**：`AUTH_MODE=supabase` 只用本地桩验证。
4. **真实语音**：麦克风权限、静音、设备中断、中文识别质量均未验证。
5. **真实 OCR**：没有视觉模型密钥。
6. **部署与上线**：未部署、未推送。
7. **打印与分页**：报告打印未在真实分页环境验证。
8. **岗位数据源**：只支持 Greenhouse，国内招聘源未接入；岗位失效未自动核验；没有岗位删除或来源撤回的独立入口。
9. **数字人、实时语音、音量检测、题型比例、单题时长自定义**：未开发。

采集相关的边界说明：

- 内网防护针对固定域名做了地址校验；若将来开放任意 URL，需要补齐 DNS 重绑定与 IPv6 映射等完整防护。
- 联系方式脱敏是有限规则。
- 来源记录是脱敏正文，不是网页完整副本；`availability` 恒为 `unknown`。
- 公开可读取不等于获得任意转载或长期存储授权，正式运营需按来源条款处理。

## 七、如何运行与验证

### 重新启动新版预览

先确认 3324 端口空闲，然后在隔离副本启动：

```powershell
cd D:\CareerForge\.validation\jobs-preview
$env:AUTH_MODE='local-demo'; $env:DATABASE_URL=' '; $env:OPENAI_API_KEY=' '; $env:OCR_API_KEY=' '; $env:ASR_API_KEY=' '
node node_modules/next/dist/bin/next start -p 3324
```

访问 `http://localhost:3324/resume`。该模式使用内存存储、规则降级，重启即清空。

### 重建隔离副本

```powershell
cd D:\CareerForge
Copy-Item -Path src,scripts,db -Destination .validation\jobs-preview -Recurse -Force
Copy-Item -Path package.json,package-lock.json,tsconfig.json,next-env.d.ts,next.config.mjs,postcss.config.mjs,tailwind.config.ts -Destination .validation\jobs-preview -Force
```

`.validation\` 已在 `.gitignore` 中忽略，不要在其中放 `.env.local` 或真实样本。

### 运行完整回归

```powershell
cd D:\CareerForge\.validation\jobs-preview
node scripts/check.mjs 3320
```

脚本会占用 3320 到 3323 以及 3997 到 3999，运行前会检查端口占用，结束时清理子进程。

### 数据库迁移

升级 PostgreSQL 前执行 `db/schema.sql`。其中包含本会话新增的 `interview_sessions.settings jsonb`。该脚本可重复执行。

### 可选能力配置

- 模型：`OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`。
- 扫描件 OCR：`OCR_API_KEY`、`OCR_BASE_URL`、`OCR_MODEL`。
- 语音转写：`ASR_API_KEY`、`ASR_BASE_URL`、`ASR_MODEL`，服务需支持 `POST /audio/transcriptions` 并返回字符串 `text`。
- 数据库：`DATABASE_URL`，启用后数据持久化。
- 认证：`AUTH_MODE=supabase` 配合 `SUPABASE_URL`、`SUPABASE_ANON_KEY`；`local-demo` 仅用于隔离的本地演示。
